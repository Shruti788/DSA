## 🔗 Problem

You are given two strings `s` and `t`.

- String `t` is generated by randomly shuffling string `s` and then adding one extra letter at a random position.
- Return the letter that was added to `t`.

---

## 💡 Approach

### Hash Map (Dictionary)

Use two dictionaries to count the frequency of characters in both strings.

1. Create two empty dictionaries: `freqS` and `freqT`.
2. Traverse `s` and count the frequency of each character.
3. Traverse `t` and count the frequency of each character.
4. Iterate through `freqT.items()`.
5. If a character is not present in `freqS`, return it.
6. Otherwise, compare the frequencies.
7. If the frequencies are different, return that character.

Since `t` contains exactly one additional character, the algorithm will always find the answer.

---

## ⏱ Complexity Analysis

### Time Complexity: **O(n + m)**

- Traversing string `s` takes **O(n)** time.
- Traversing string `t` takes **O(m)** time.
- Iterating through the frequency dictionary of `t` takes at most **O(m)** time.

Therefore,

**Total Time Complexity = O(n + m)**

where:

- **n** = length of `s`
- **m** = length of `t`

---

### Space Complexity: **O(n + m)**

- `freqS` stores the frequency of characters in `s`.
- `freqT` stores the frequency of characters in `t`.

In the worst case, both dictionaries store all unique characters.

Therefore,

## **Space Complexity = O(n + m)**
